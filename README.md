# EV Market Intelligence Agent

Project 2 for the AWS AI & ML Scholars program (Building No-Code AI Agents with Amazon Quick).

I built a Market Intelligence Agent in Amazon Quick Suite to help an EV maker decide how to position, price, and launch a new mid-range EV priced between $35K and $55K.

## What's in this repo

- **Market_Intelligence_Research_Brief_Reyes.pdf** is the completed research brief. Open this one to read it in the browser.
- **Market_Intelligence_Research_Brief_Reyes.docx** is the same brief in Word format.
- **screenshots/** has 43 numbered screenshots of the work in Quick Suite, in the order it was done.

## How it was built

1. Uploaded the Kaggle EV Market Analytics Dataset (ev_market_2026.csv) to a Space called EV Market Intelligence.
2. Created the chat agent "Market Intelligence Agent – EV Market" with that Space as its knowledge source.
3. Ran Quick Research on the 2025–2026 global EV market, which produced a report citing 46 sources.
4. Had the agent produce a Market Analysis, calculate figures directly from the dataset, run a reliability review of each insight, and write the final brief.
5. Saved every output to the Space.

## Main findings

- Europe is the strongest launch market, and North America is the weakest after the US tax credit ended.
- A price between $35K and $42K is needed to compete with the Chevrolet Equinox EV and the repriced Hyundai Ioniq 5.
- About 300 miles of range is now the baseline among mid-range competitors.
- Faster charging could set the car apart, but there is no consumer data yet to prove it.

Overall confidence is Medium. The dataset is synthetic, so it was used for patterns only, and all real market figures come from Quick Research.
